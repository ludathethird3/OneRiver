# One River, Many Lives

## [▶ Play the interactive documentary](https://ludathethird3.github.io/OneRiver/One%20River_%20many%20lives.html)

An interactive documentary exploring the Nile River through personal memories, places, wildlife and the lives connected by its waters. Built in Twine (Harlowe), with clickable scenes and audiovisual storytelling. This project is a work in progress.

## Project files

`One River_ many lives.html` contains the exported Twine story, its stylesheet and story engine. Images and audiovisual files are stored separately and must keep their relative paths. To edit the story, import the HTML into Twine, make changes and publish it to HTML again.
